📰 개인정보처리방침

시행일: 2026년 6월 4일  |  뉴스 브리핑

뉴스 브리핑(이하 "앱")은 사용자의 개인정보를 소중히 여기며, 「개인정보 보호법」 및 관계 법령을 준수합니다. 본 방침은 앱이 수집하는 정보의 종류, 이용 목적, 보관 기간 및 사용자 권리를 안내합니다.

1. 수집하는 정보

앱은 서비스 제공을 위해 아래 정보를 수집합니다.

  • 대략적 위치 정보 — 현재 날씨 제공 목적 (정밀 위치 미수집, 거부 시 서울 기준으로 표시)
  • 광고 식별자(광고 ID) — 무료 사용자에게 표시되는 광고 제공 목적 (Google AdMob)
  • 앱 이용·상호작용 기록 — 화면 사용, 기능 사용 등 익명 통계 (Firebase Analytics)
  • 진단·오류 정보 — 비정상 종료 로그 등 (Firebase Crashlytics)
  • 푸시 알림 토큰 — 속보·브리핑 알림 발송 목적 (Firebase Cloud Messaging)
  • 친구 초대 식별 코드 — 초대 보상 집계 목적의 익명 코드 (개인 식별 정보 아님, Firebase Firestore)
  • 앱 내 사용 기록 — 검색 키워드, 클릭한 기사, 즐겨찾기, 관심사·알림 설정 (기기 내 저장, 기기 자동 백업 시 사용자 본인 Google 계정으로만 백업)
  • 구독 정보 — Google Play 결제 여부 (Google이 처리, 결제수단 정보는 직접 수집하지 않음)

2. 수집하지 않는 정보

  • 이름, 이메일, 전화번호 등 식별 가능한 개인정보
  • 주소, 생년월일, 성별 등 민감정보
  • 금융정보 (결제는 Google Play에서 처리)
  • 연락처, 사진, 파일 등 기기 내 개인 데이터

3. 정보의 이용 목적

  • AI 맞춤 뉴스 피드 개인화
  • 검색 기록 기반 키워드 추천
  • 위치 기반 날씨 정보 제공
  • 속보·브리핑 푸시 알림 발송
  • 프리미엄 구독 상태 확인

4. 제3자 서비스 및 데이터 공유

앱은 아래 외부 서비스를 사용합니다. 각 서비스의 개인정보처리방침을 함께 확인하세요.

  • Google AdMob — 광고 제공(무료 사용자). 광고 식별자를 광고 목적으로 Google과 공유합니다. (Google 개인정보처리방침)
  • Firebase Analytics / Crashlytics / Cloud Messaging / Firestore — 익명 이용 통계, 오류 진단, 푸시 알림, 초대 보상 집계 (Google) (Google 개인정보처리방침)
  • Google Gemini AI — AI 요약·분석 기능 (Google 개인정보처리방침)
  • 네이버 뉴스 API — 뉴스 콘텐츠 제공 (네이버 이용약관)
  • OpenWeatherMap — 날씨 정보 제공 (대략적 위치 좌표 전달)
  • Google Play Billing — 구독 결제 처리

광고 식별자를 제외하고, 위 분석·진단·초대 데이터는 서비스 운영 목적의 처리이며 제3자에게 판매하지 않습니다.

5. 데이터 저장 위치 및 보관 기간

  • 검색·클릭 기록, 즐겨찾기, 관심사·알림 설정 — 기기 내부 저장이 원칙이며, 기기의 Google 자동 백업 기능 사용 시 사용자 본인 계정으로만 백업·복원됩니다.
  • 익명 통계·진단·푸시 토큰·초대 집계 데이터 — Firebase(Google) 서버에 저장되며, 서비스 운영에 필요한 기간 동안 보관됩니다.
  • 앱 삭제 시 기기 내 데이터는 함께 삭제됩니다. 익명 통계 등 서버 데이터의 삭제는 아래 문의로 요청할 수 있습니다.

6. 사용자 권리

  • 데이터 초기화 — 설정 → 알고리즘 초기화로 검색·클릭 기록 삭제 가능
  • 알림 거부 — 기기 설정 또는 앱 내 설정에서 알림 비활성화 가능
  • 위치 권한 거부 — 날씨 기능 미사용 시 위치 권한 거부 가능
  • 구독 해지 — Google Play → 구독 관리에서 언제든 해지 가능
  • 광고 맞춤설정 거부 — 기기 설정 → Google → 광고에서 광고 ID 재설정·맞춤광고 거부 가능
  • 데이터 삭제 요청 — 서버에 저장된 익명 데이터의 삭제는 아래 이메일로 요청 가능
  • 앱 삭제 — 앱 삭제 시 기기 내 모든 데이터 완전 삭제
