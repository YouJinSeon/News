# 뉴스 브리핑 — 화면별 기능 정리 (목업용)

**목적:** 디자인 목업 제작을 위한 화면·기능 명세
**디자인 방향:** 따뜻한 카드 미니멀 — 화이트/연핑크 배경(`#FFFFFF` / `#FDE7EC`), 흰 카드 + 얇은 헤어라인 보더(그림자 최소), **오렌지(`#FF8F00`) 포인트**, 여백 넉넉, 둥근 카드(라운드 12~16), 차분하고 신뢰감 있는 톤
**플랫폼:** Android (Jetpack Compose, Material3) · 한국어 UI
**브랜드:** 신문 카드 + 우상단 'AI' 오렌지 뱃지 로고.
**마스코트 캐릭터는 사용하지 않음** — 일러스트 대신 아이콘·도형·이모지(✨🔥📊 등)와 깔끔한 타이포로 표현. (캐릭터 자리는 비우거나 로고/아이콘으로 대체)

## 공통 (모든 화면)
* 하단 탭바 5개: **홈 · 검색 · 즐겨찾기 · 리포트 · 설정**
* 카테고리 색상 시스템: 주식/투자🟢(그린) · 정치/경제🔵(블루) · 글로벌🍷(와인) · 스포츠🌿(민트)
* AI 요소 표시: ✨ 아이콘 + 블루 계열 (AI 요약·분석·질문)
* 읽은 기사 = 반투명 처리, 카드 = 라운드 + 옅은 보더
* 알림 아이콘: 작은(상태바)=흰 신문 실루엣 / 큰=컬러 앱 아이콘

---

## 1. 온보딩 (첫 실행, 2단계)
**현재 구현**
* 1단계 가치 데모: "AI가 매일 핵심 뉴스만 골라드려요" + AI 요약 예시 카드 + 기능 3줄(⚡속보·🔍심층분석·📊리포트)
* 2단계 관심사 선택: 2열 카드 4개(📈주식/🏛️정치경제/🌍글로벌/⚽스포츠), 알림 권한 사전 안내 → [시작하기]

**예정**
* 닉네임 입력(개인화 인사 "○○님을 위한 브리핑")
* 온보딩 마지막에 듣는 뉴스/AI 질문 데모 한 컷

## 2. 홈 (오늘의 브리핑)
**현재 구현**
* 상단바: "오늘의 브리핑"+날짜 / 🎧듣기(브리핑 음성재생)·⭐프리미엄(무료만)·🔄새로고침
* 날씨·시세 행: 날씨 · KOSPI · 나스닥 · 원/달러(등락 색)
* 카테고리 탭: 전체 + 구독 카테고리 + ✨맞춤 피드
* 🔥오늘의 헤드라인(TOP1 큰 카드) / 📈주식·🏛️정치경제 가로 스크롤 / 📊지금 주목받는 뉴스(순위) / 🕐최신 뉴스
* 읽은 기사 흐리게 · 하단 배너(무료) · 더보기 잠금카드 · 당겨서 새로고침 · 빈 상태
* 10분 자동 갱신 + 백그라운드 FCM 갱신

**예정**
* **"오늘의 나를 위한 브리핑"** — 관심사를 묶어 AI가 뉴스레터처럼 써주는 생성형 일일 다이제스트
* 듣는 뉴스 재생 중 하단 **미니 플레이어 바**(재생/정지/다음)
* 연속 읽기 **스트릭/뱃지**
* 체류·읽은 수 기반 추천 강화

## 3. 기사 상세 — 핵심 화면
**현재 구현**
* 상단바: 뒤로 · 🔊듣기 · ⭐즐겨찾기 · 🔗공유
* 카테고리 뱃지 + 출처 + 시간 / 제목
* ✨**AI 간략 요약**(무료 3회/일, 소진 시 "광고 보고 +3회 충전")
* 본문(RSS 요약), 잘린 매체는 "요약만 제공 → 전체 기사 읽기" 안내
* 📈**AI 심층 분석**(무료=광고 1회 / 프리미엄=자동): 요약·투자 시사점·토픽 팔로우 칩
* 💬**AI에게 질문하기**: 프리셋 칩(쉽게 설명/왜 중요/배경/다음) + 직접 입력
* [전체 기사 읽기] → 웹뷰 / 하단 배너(무료) / 기사 4회 열람마다 전면 광고

**예정**
* TTS **속도·목소리 선택**
* 프리미엄: 잘린 기사 **자동 AI 정리**(무료는 전환 레버로 유지)
* 기사 번역 / 관련 기사 추천

## 4. 검색
**현재 구현**
* 검색바 / 자주 검색한 키워드(칩) / 최근 검색(전체삭제, 항목별 ×) / 검색 결과

**예정**
* 실시간 인기 검색어·트렌드
* 음성 검색
* 검색 결과 정렬·필터(최신/관련도)

## 5. 즐겨찾기
**현재 구현**
* "내 관심사 키워드"(학습 키워드 칩, 문장부호 정제됨) + 새로고침
* 즐겨찾기 기사 목록(무료 0/20 제한) / 빈 상태

**예정**
* 폴더·태그 분류
* 오프라인 저장(읽기)
* 키워드 → 해당 뉴스 모아보기

## 6. 리포트 (주간 리포트)
**현재 구현**
* "이번 주 브리핑"(N월 N주차) / 관심사 분포(% 바) / ✨AI 취향 분석 / 핵심 키워드(#칩) / 다음 주 주목 이슈
* "프리미엄=매일 리포트" 안내 + [업그레이드] (무료=광고 1회)

**예정**
* **일간 리포트**(프리미엄)
* 읽은 수·체류시간 통계 그래프
* 리포트 **공유 카드**(SNS용)

## 7. 설정
**현재 구현**
* 구독(업그레이드/구독 관리) · 관심사 토글 · 알림(속보·정기·야간·토픽·키워드) · **친구 초대(AI 사용권 보상, 진행도)** · 다크모드 · 기타(알고리즘 초기화·평가·문의·개인정보처리방침·버전)

**예정**
* **Google 로그인 + 클라우드 동기화**(현재는 Android 자동 백업)
* 알림 시간 커스텀 / 배터리 최적화 제외 안내
* 테마·글자크기 설정

## 8. 페이월 (프리미엄)
**현재 구현**
* 헤더 👑 / (A/B B형) 🔥긴급 배너
* 월간 ₩6,900(7일 무료체험·혜택 6개·체험 후 가격) / 연간 ₩58,800(29% 절약·월환산)
* 구매 복원 · **구독 약관 블록**(체험·자동결제·해지 명시)

**예정**
* **무료 vs 프리미엄 비교표**

* 사회적 증거(후기·사용자 수)

## 9. 기타 화면 / 시스템
**현재 구현**

**예정**

## 데이터·정책 메모 (디자인 시 참고)
* **무료 정책:** 피드·검색·속보·즐겨찾기(제한)·위젯·듣기 = 무료. **AI 간략요약** 하루 3회 무료(광고 보면 충전), **AI 심층분석** 광고 1회/프리미엄 무제한. **친구 초대 시 AI 보너스 사용권**.
* **프리미엄:** 광고 제거 + AI 무제한 + 관심사·즐겨찾기 무제한 (월 ₩6,900·7일 무료체험 / 연 ₩58,800).
* **뉴스 소스:** 네이버 검색 API + 주요 언론사 RSS. **전문은 원문 링크(웹뷰)** 로 — 저작권상 본문 스크래핑 안 함. 일부 매체는 RSS가 요약만 제공.
* **백그라운드:** 포그라운드 서비스 없이 WorkManager + **FCM 무음 신호(15분)** 로 피드·브리핑·속보 갱신.
* **Firebase:** Analytics·Crashlytics·FCM·Firestore(초대 카운트)·App Check.
* **백업:** Android 자동 백업으로 관심사·즐겨찾기·설정 복원(같은 구글 계정).
* **오프라인 우선:** Room 로컬 저장, 추후 클라우드 동기화.
